# Super Jonas — Mission CP

Jeu éducatif pour préparer l'entrée au CP : nombres, dizaines et unités, additions, lettres, syllabes et défis mixtes.

## Jouer

Ouvrir `index.html` dans un navigateur récent. Les consignes vocales utilisent la synthèse vocale du navigateur (français). Les étoiles sont sauvegardées localement sur l'appareil.

## Publier avec GitHub Pages

Dans **Settings → Pages**, sélectionner **Deploy from a branch**, branche **main**, dossier **/(root)**, puis enregistrer.
